# Selfiemirror Vorschau

Interaktive Vorschau: Kundenseite (Anfrageprozess mit Richtpreis und Verfügbarkeit), Admin-Bereich (Dashboard, Kalender, Anfragen, Preise, Geräte) und Ablauf & Angebot.

Statische Seite (`index.html`), ausgeliefert mit `serve`. Railway erkennt `package.json` und startet `npm start`.

Lokal testen: `npm install && npm start`, dann http://localhost:3000
